# 흑 · 백 — Whistle POC

눈을 감은 검객 **흑**과 휘파람으로 시야를 여는 주인 **백**. 휘파람이 이어지는 짧은 순간에만 적을 보고 연속 베기로 호위 길을 여는 1인칭 Unity POC입니다.

## 실행

Unity **6000.0.55f1**에서 프로젝트를 열고 `Whistle POC > Open prototype` 메뉴를 실행한 뒤 Play를 누르세요. 생성된 `Assets/Scenes/WhistlePOC.unity` 씬에서도 바로 실행됩니다. 타이틀에서 **호위 시작** 또는 Enter를 누릅니다.

## 조작

| 입력 | 동작 |
|---|---|
| Space 또는 우클릭 | 짧게: 8m 감지 / 0.3초 이상 유지: 30m 감지 / 시간 12% 속도 |
| Tab / 화면의 검 모드 버튼 | 드래그 ↔ 클릭 일괄 베기 전환 |
| 좌클릭 유지 + 드래그 (드래그 모드) | 궤적이 공개된 적을 가로지르면 베기 (6.5m 이내) |
| 좌클릭 한 번 (클릭 모드) | 휘파람 중 화면에 보이는 적 전체를 동시에 공격 |
| 휘파람 키 놓기 | 시야 닫기, 숨 회복, 정상 시간 |
| Esc | 일시정지 / 계속 |
| R | 업그레이드를 초기화하고 처음부터 다시 시작 |
| Enter | 타이틀 / 정비 / 결과창의 첫 선택 |

이동은 자동입니다. 휘파람 전에는 적의 모습이 숨겨지고, 각 적 유닛에 붙은 원형 파동이 발걸음마다 하나씩 작게 시작해서 커진 뒤 사라집니다. 첫 원이 다 퍼진 다음 두 번째, 세 번째 원이 차례로 반복되며 동시에 커지지 않습니다. 발걸음 소리와 실제 적 위치의 파동으로 거리감을 알려줍니다. 파동은 먼 적부터 작고 희미한 원으로 천천히 퍼집니다. 가까워지면 크고 선명해지고 주기가 빨라집니다. 사거리 경계에서 갑자기 켜지지 않습니다. 휘파람을 불어도 배경과 적의 면은 계속 숨겨집니다. 초음파처럼 퍼지는 소리가 가까운 곳부터 먼 곳까지 도달하면서 적과 지형의 윤곽선만 약 0.48초 나타났다가 흐려집니다. 파동은 초당 45m로 전파되며 휘파람 중 0.6초 간격으로 반복됩니다. 지형 선은 적보다 훨씬 희미합니다. 검 사거리 안의 적 윤곽은 더 선명합니다. 가까운 적일수록 발걸음이 빨라지고 소리가 커집니다. 적 접근 속도는 이전의 1.5배입니다. 백까지 도달하면 밝은 흰색 파동과 경고음으로 0.45초간 공격을 예고한 뒤 체력을 1 깎으며, 이후 0.95초 주기로 반복합니다. 죽이지 않으면 그 자리에 계속 남습니다. 목적지에 도착해도 남은 적을 처치해야 정비하거나 클리어할 수 있습니다. 백의 체력은 5이며, 세 구간을 통과하면 성공합니다. 각 구간은 정상 시간 기준 24초이며 휘파람을 사용하는 만큼 실제 플레이 시간이 늘어납니다.

기본은 드래그 모드입니다. Tab 또는 왼쪽 아래 모드 버튼으로 언제든 전환할 수 있으며, 선택은 재시작과 구간 전환 후에도 유지됩니다. 드래그 모드에서는 좌클릭만 하거나 누른 채 가만히 있으면 공격하지 않습니다. 드래그 궤적이 여러 적을 가로지르면 한 번에 벱니다. 갑옷 적은 다른 적처럼 지나친 뒤 다시 베어야 하며, 같은 적에 대한 타격 간격은 0.18초입니다. 헛베기는 다음 타격 판정을 막지 않습니다. 드래그 선이 머리나 몸통을 가로지르면 즉시 판정되며 밝은 잔상이 따라옵니다.

클릭 모드는 거리와 관계없이 휘파람 중 반향으로 감지되어 실제 시야에 들어온 적을 한 번씩 타격하고, 각 적에 흰 검격 선을 빠르게 그립니다. 화면 밖 적과 휘파람 전에 숨겨진 적은 공격하지 않습니다. 갑옷은 기존 검 공격력을 따르므로 기본 검으로는 두 번 클릭해야 합니다. 버튼을 누른 채 유지하면 공격이 반복되지 않으며, 클릭 간 최소 간격은 0.28초입니다. 가까운 표창(6.5m 이내)도 함께 쳐냅니다. 모드 버튼을 누르는 동작은 공격으로 처리하지 않습니다.

휘파람은 기본 1.1초입니다. 휘파람을 끈 뒤 0.2초를 기다리고, 초당 0.6초의 숨을 회복합니다. 숨을 다 쓰면 키를 놓아야 다시 사용할 수 있습니다. 구간 사이에서 체력 1을 회복하고 **휘파람 지속시간 +0.6초** 또는 **검 공격력 +1**을 선택합니다. 2구간부터 두 번 베어야 하는 갑옷 적이 등장합니다.

각 무리에 원거리 적이 한 명 섞입니다. 원거리 적은 15m 안에서 짧은 공격 예고 뒤 표창을 던지고, 가까워지면 근접 공격으로 전환합니다. 휘파람 전에는 날아오는 표창 위치에 네모(ㅁ) 파동만 표시되고, 휘파람 중에는 표창의 회전하는 윤곽선이 감지됩니다. 검 사거리 6.5m 안의 표창을 좌클릭 드래그로 쳐낼 수 있습니다. 방치한 표창은 백의 체력을 1 깎습니다. 목적지에서는 날아오는 표창까지 처리해야 정비할 수 있습니다.

## 추가한 실험 요소

- 짧은 휘파람은 8m까지만 감지합니다. 0.3초 이상 유지하면 넓은 반향을 추가로 보내 30m까지 감지합니다. 반향은 거리에 따른 전파 시간이 있으며 오래 부는 만큼 숨을 씁니다.
- 돌진 적은 12m 안에서 발걸음을 멈추고 0.45초 예고한 뒤 0.7초 동안 3.2배 속도로 파고듭니다. 멈춘 발소리와 빨라지는 발자국이 단서입니다.
- 기만 적은 실제 위치 옆에서 가짜 발자국 소리와 파동을 만듭니다. 휘파람의 반향에는 실제 적의 윤곽만 나타나며 가짜 파동은 공격 대상이 아닙니다.
- 근접 공격 직전 0.16초 안에 처치하거나, 1.8m 안까지 온 표창을 쳐내면 숨을 0.18초 돌려받습니다. 돌진 적을 마지막 순간에 베어도 적용됩니다. 흰 파동과 메시지로 성공을 알리고, 한 번의 공격에서는 한 번만 보상합니다. 두 검 모드 모두 적용되며 최대 숨을 넘지 않습니다.
- 수치는 `Whistle Game > Sound reading and counterplay`에서 조절합니다. 돌진/기만 적도 별도 프리팹으로 저장되어 있습니다.

## 확인할 핵심 재미

- 소리와 작은 파동으로 위험을 예상한 다음 휘파람을 여는 타이밍.
- 한 번의 숨 안에서 커서를 옮기며 여러 적을 빠르게 베는 느낌.
- 숨을 아끼는 것과 백을 지키기 위해 오래 보는 것의 균형.
- 긴 숨과 갑옷을 한 번에 베는 검 중 정비 선택의 차이.

## 구성과 조정

`WhistleGame.cs`는 진행, 입력, 숨, 공격, 정비를 담당하고 `FirstPersonStage.cs`는 저장된 프리팹의 표시와 애니메이션을 제어합니다. `WhistleInk.cs`는 HUD를, `PooledSwordGraphic.cs`는 검격 효과를 그립니다. UI와 합성 오디오는 저장된 씬 에셋을 사용합니다. UI는 맑은 고딕이며 Windows 데스크톱 POC를 기준으로 합니다.

메인 씬에는 `Whistle Game`, `Environment`, `Ink Canvas`, `Spawn Points`, `Player - Black Swordsman`이 저장되어 있습니다. `Whistle Game` 인스펙터에서 숨, 적 속도, 반향, 사거리, 체력 등을 조절하세요. `Spawn Points`의 Transform을 이동하면 실제 적 등장 위치가 바뀝니다. 재시작 시 지속시간과 검 공격력은 씬에 설정한 기본값으로 돌아갑니다.

`Assets/Whistle/SceneAssets/Prefabs`에 모든 적, 표창, 원형/사각 파동, 반향 전선, 검격 효과와 맵·플레이어·검·UI·스폰 지점 프리팹이 있습니다. 형태를 바꾸려면 해당 프리팹을 편집하세요. `Editor Preview`는 편집 모드 배치 확인용이며 플레이 중 숨기고 빌드에서는 제외합니다.

`Whistle Game > Object Pool Manager`의 Catalog에서 프리팹별 Prewarm 수를 조절합니다. 시작할 때 미리 생성하고, 적·표창·파동·검격은 `Spawn`으로 빌려 쓰고 `Return`으로 반환합니다. 재사용할 때 위치·회전·크기, 렌더러 색상과 효과 연결을 초기화하며 재시작 시 모든 활성 오브젝트를 반환합니다. 풀이 부족할 때만 프리팹 인스턴스를 추가합니다. 실행 중 프리미티브나 컴포넌트를 조립하는 코드는 없습니다.

`Whistle POC > Edit level layout`은 UI를 씬 뷰에서만 숨겨 맵 배치를 보기 쉽게 합니다. `Edit UI layout`은 UI를 다시 표시하고 Canvas를 선택합니다. 이 표시 전환은 게임 화면에 영향을 주지 않습니다.

`Whistle POC > Run gameplay smoke test`는 실제 Play Mode에서 공격 제한, 공개/시간 전환, 연참, 정비, 갑옷, 성공, 실패, 재시작을 확인하고 `POCVerification/`에 결과를 저장합니다. 이 검사는 진행을 초기화하므로 플레이 중이 아닌 상태에서 실행하세요.
